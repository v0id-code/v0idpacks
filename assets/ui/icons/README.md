# Editor icons

Feather icons by Cole Bemis, distributed under the included MIT license.
Source: https://github.com/feathericons/feather, retrieved through https://api.iconify.design/feather/ on 2026-10-26.

The SVG files are the originals. The white 16×16 PNG exports are generated with Sharp; Java2D tints and caches them using the existing text/accent colors. The game loads these local PNGs, with no runtime download or SVG dependency. Keep SVG and PNG names aligned when replacing an icon. The JAR also includes `FEATHER-LICENSE.txt` beside the icons.
